# Social card fonts

Merriweather Latin regular (400) and bold (700), downloaded from Fontsource on
2026-10-09. These are artwork inputs, not browser font dependencies. The existing
site font loading is unchanged. Redistribution is under the included SIL OFL.

Sources:
- https://cdn.jsdelivr.net/fontsource/fonts/merriweather@latest/latin-400-normal.woff
- https://cdn.jsdelivr.net/fontsource/fonts/merriweather@latest/latin-700-normal.woff
- https://github.com/google/fonts/blob/main/ofl/merriweather/OFL.txt

The committed files make `npm run social:generate` independent of network access.
